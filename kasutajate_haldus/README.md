# bash_skriptimine

Linux skriptimine - BASH haldus, praks1: kasutajate haldus.

| Skript | Ülesanne |
|---|---|
| lisa_kasutaja | Ül 1 - kasutaja loomine käsurea parameetri abil |
| kasutajad_failist | Ül 2 - kasutajad failist (kutsub lisa_kasutaja) |
| kasutajad_failist_parooliga | Ül 3 - kasutajad paroolidega failist (kasutaja:parool) |
| kasutajad_ja_paroolid | Ül 4 - kasutajad ja paroolid eraldi failides |
| kasutajad_genereeritud_paroolidega | Ül 5 + Ül 6 - pwgen paroolid, logifail, ainult root |
| kustuta_kasutajad | abiskript - failis olevate kasutajate kustutamine |

Testfailid: kasutajad, kasutajad_paroolid, paroolid.

Kasutajate haldamiseks on vaja root õigusi (sudo).
